## 📋 Overview

Cerberus is a comprehensive web-based red team platform designed for penetration testing, security research, and educational purposes. It provides a unified interface for various security tools and frameworks.

## ✨ Features

### 🔍 Network Reconnaissance
- **Port Scanner** - Comprehensive network port scanning
- **Vulnerability Scanner** - CVE detection and analysis
- **DNS Enumeration** - DNS record discovery
- **Subdomain Finder** - Automated subdomain enumeration
- **Network Analysis** - Topology mapping and device discovery

### 💣 Exploitation Tools
- **Exploit Database** - Searchable exploit repository
- **SQL Injection Tester** - Automated SQL injection testing
- **XSS Tester** - Cross-site scripting vulnerability detection
- **Payload Generator** - Custom payload creation

### 🎣 Social Engineering
- **Phishing Campaigns** - Campaign creation and management
- **Email Templates** - Pre-built phishing templates
- **Target Tracking** - Campaign analytics

### 🕵️ OSINT Tools
- **WHOIS Lookup** - Domain registration information
- **Email Harvester** - Email address collection
- **Social Media Intelligence** - Data gathering

### 🔐 Cryptography
- **Hash Cracker** - Password hash cracking with multiple algorithms

### 📊 Monitoring & Management
- **Real-time Monitoring** - System resource and network monitoring
- **Target Watchlist** - Track and manage targets
- **Activity Logs** - Comprehensive event logging
- **Advanced Terminal** - Multi-session terminal emulator

## 📦 Installation & Development

### Prerequisites
- Node.js 18+ or Bun 1.0+
- Modern web browser

### Setup

```bash
# Clone the repository
git clone <YOUR_GIT_URL>
cd <YOUR_PROJECT_NAME>

# Install dependencies
npm install
# or
bun install

# Start development server
npm run dev
# or
bun dev

# Build for production
npm run build
```
